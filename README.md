# GraphicsViewer
- 간단하게 OPENGL 렌더링 공부겸 테스트 해보는 툴
- Assimp(3D모델링 로드), GLEW(opengl 확장 라이브러리), GLFW(opengl 창, 컨텍스트, 입력)
- 영상 : https://tv.kakao.com/v/456951806

## 현재 진행도
- 3D 물체 렌더링
- 그림자 구현 
- 디렉셔널 라이트
- 싱글톤 템플릿화
- 액터, 컴포넌트 기틀 구성
- 인풋 전역적으로 받아오도록 구현

## visual studio 필터 구조
- CharaterViewer : 테스트에 실제 사용하는 코드, Game에서 각 객체 상속받아 구현후 띄운다.
- Engine : 렌더링, 메시, 인풋등 구현
- Game : 게임에 사용되는 (게임 전체 전역 변수 모음, 맵별 객체, 액터, 컴포넌트) 구현
- Shaders : GLSL 셰이더 파일
- Utils : 액터, 전역변수, 싱글톤, imgui(윈도우창)등 유틸성 모음 
- Assets : 사용할 에셋 모음

## 추가적으로 해볼것
- 포인트 라이트, 스포트 라이트등 광원 기능 추가
- 퐁 셰이딩 PBR로 변경
- 2D 텍스트
- 툰 셰이딩, 포스트 프로세싱(외곽선)  
- 큐브맵, 스카이 스피어
- 다중광원 처리방법(후면 렌더링)
- 테셀레이션, 지오메트리 쉐이더 만들어서 테스트 (아마 울퉁불퉁한 지형같은거)
- 물리는 먼저 오픈소스([JoltPhysics](https://github.com/jrouwe/JoltPhysics)) 사용해볼 예정
